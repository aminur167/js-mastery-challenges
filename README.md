# GitHub Issues Tracker - JavaScript DOM Project

An interactive GitHub issues dashboard built with vanilla JavaScript. This project focuses on DOM manipulation, dynamic component rendering, state filtering, and handling asynchronous API/mock data.

## What's Inside

- **Issue Listing**: Display issue cards with labels, author details, creation timestamp, and status indicators.
- **Status Filtering**: Seamless switching between *All*, *Open*, and *Closed* issue views.
- **Search Querying**: Real-time client-side text filtering across titles and descriptions.
- **Responsive Layout**: Flexbox-based layout optimized for mobile and desktop viewports.

## Tech Stack

- **JavaScript**: ES6+ features (arrow functions, array methods, destructuring, template literals)
- **HTML5 / CSS3**: Clean semantic layout and GitHub-inspired UI themes
